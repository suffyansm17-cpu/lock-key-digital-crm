# Lock & Key Digital CRM — Starter

Includes Login, Admin/HR role-based navigation, Dashboard and Employee Management.

Demo:
Admin: admin@lockandkeydigital.com / Admin@123
HR: hr@lockandkeydigital.com / HR@12345

Run:
npm install
npm run dev

Then open http://localhost:3000

IMPORTANT: This starter uses demo authentication and in-memory employee data. Do not put real Aadhaar, PAN, bank details or other sensitive documents into it yet. The next build should replace this with Supabase authentication, database, secure file storage and server/database-enforced permissions.
